# Ridge and CV, 0.8.0

The pure PHP implementation matches native fit_ridge and cv_ridge. Shared
fixtures cover glmnet fits, weighted day-fold CV, MASS conversion, lmridge
conditional covariance per sigma squared, and heating-shaped inputs. Conditional
uncertainty holds lambda and active bounds fixed and is not coverage-valid.
See docs/ridge.md for the observed scaling and weighted CV specification.

Focused ridge, API, fit-object, summary, and prediction tests passed: 131 tests,
8,872 assertions on PHP 8.4. PHPCS passed. Numerical validation has 5,988 saved
comparisons per implementation with maximum absolute error 6.855e-8. Ridge-only
benchmarks are copied from the paired native run, with both implementations
measured. Native source is pinned in tests/fixtures/REFERENCE.

CI caught a negated comparison in constant-column bounds validation. Rewrote
it as direct comparisons to follow the repository NaN/OPcache safety policy.
Focused ridge and NaN safety tests pass after the correction.
